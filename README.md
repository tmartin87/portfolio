## 🛠️ Tecnologías

- **HTML5** — estructura semántica
- **Tailwind CSS v4** — estilos y diseño responsive
- **JavaScript vanilla** — navegación, templates dinámicos y animaciones
- **IntersectionObserver API** — animaciones al hacer scroll

## ✨ Características

- Diseño **responsive** — adaptado a móvil, tablet y desktop
- **Animaciones al scroll** con IntersectionObserver
- **Animación de entrada** en el hero con CSS keyframes
- Menú de navegación con apertura/cierre en móvil
- Cards de proyectos generadas dinámicamente desde un array de datos
- Sección de reseñas con template reutilizable
